# README imagery

`saved-outputs.png` is an unaltered browser screenshot of Outtake's live Saved
Outputs view, captured on 2026-09-16 for the project README at the owner's request.
It shows six real local exports, sorting, reopening, downloading and deletion
controls. It is product documentation, not a mockup or a semantic acceptance test.

The screenshot contains frames from Silicon Valley, The Venture Bros., Repo Man,
and Blade Runner. Those works belong to their respective rights holders. Source
media and exported clips are not included in this repository. The capture excludes
browser chrome, local filesystem paths, credentials and authenticated session URLs.
